# 多账号任务时间记录使用说明

## 📋 功能概述

为了支持多账号分别记录不同任务的执行时间，我们在 `AccountInfo` 中添加了以下字段：

- `last_complete_time`: 多账号日常任务完成时间
- `last_kekkai_utilize_time`: 寄养任务完成时间
- `last_kekkai_activation_time`: 挂卡任务完成时间
- `last_demon_encounter_time`: 逢魔任务完成时间

## 🔧 配置文件结构

在 `config/switch.json` 中，每个账号的配置会自动包含这些时间字段：

```json
{
  "account_list_1": {
    "character": "陸月是你的謊言",
    "svr": "雀之羽",
    "account": "jiyibanana@163.com",
    "account_alias": "jiyibanana",
    "apple_or_android": false,
    "last_complete_time": "2023-01-01 00:00:00",
    "last_kekkai_utilize_time": "2023-01-01 00:00:00",
    "last_kekkai_activation_time": "2023-01-01 00:00:00",
    "last_demon_encounter_time": "2023-01-01 00:00:00"
  }
}
```

## 💻 代码使用示例

### 1. 在任务脚本中更新账号任务时间

在任务完成后，调用 `update_account_task_time` 方法更新对应账号的任务时间：

```python
# 在寄养任务中
class ScriptTask(GameUi, ReplaceShikigami, KekkaiUtilizeAssets):
    def run(self):
        # ... 执行寄养任务 ...
        
        # 任务完成后，更新当前账号的寄养任务时间
        # 假设当前登录的账号信息为 current_account
        self.update_account_task_time(
            character="陸月是你的謊言",
            svr="雀之羽",
            task_name="KekkaiUtilize"
        )
        
        raise TaskEnd
```

### 2. 支持的任务名称

目前支持以下任务名称：

- `'KekkaiUtilize'`: 寄养任务
- `'KekkaiActivation'`: 挂卡任务
- `'DemonEncounter'`: 逢魔任务

### 3. 在多账号日常任务中使用

```python
# 在 MultiAccountDaily 中
class ScriptTask(GameUi, MultiAccountDailyAssets):
    def run(self):
        for account_info in self.multi_conf.account_list:
            # 切换账号

            if success:
                # 执行寄养任务
                self.run_kekkai_utilize(account_info)
                
                # 执行挂卡任务

        # ... 执行任务逻辑 ...

        self.config.save()
    
    def run_kekkai_activation(self, account_info):
        """执行挂卡任务"""
        # ... 执行任务逻辑 ...
        
        # 更新该账号的挂卡任务时间
        self.multi_conf.update_account_task_time(account_info, 'KekkaiActivation')
        self.config.save()
    
    def run_demon_encounter(self, account_info):
        """执行逢魔任务"""
        # ... 执行任务逻辑 ...
        
        # 更新该账号的逢魔任务时间
        self.multi_conf.update_account_task_time(account_info, 'DemonEncounter')
```

### 4. 判断是否需要执行任务

可以根据上次执行时间判断是否需要再次执行：

```python
from datetime import datetime, timedelta

def should_run_task(account_info, task_name, interval_hours=6):
    """
    判断是否需要执行任务
    :param account_info: 账号信息
    :param task_name: 任务名称
    :param interval_hours: 时间间隔（小时）
    :return: True 表示需要执行，False 表示不需要
    """
    task_time_mapping = {
        'KekkaiUtilize': account_info.last_kekkai_utilize_time,
        'KekkaiActivation': account_info.last_kekkai_activation_time,
        'DemonEncounter': account_info.last_demon_encounter_time,
    }
    
    last_time = task_time_mapping.get(task_name)
    if not last_time:
        return True
    
    # 计算时间差
    time_diff = datetime.now() - last_time
    return time_diff >= timedelta(hours=interval_hours)

# 使用示例
for account_info in self.multi_conf.account_list:
    # 判断是否需要执行寄养任务（6小时间隔）
    if should_run_task(account_info, 'KekkaiUtilize', interval_hours=6):
        logger.info(f"账号 {account_info.character} 需要执行寄养任务")
        # 执行任务...
    else:
        logger.info(f"账号 {account_info.character} 寄养任务还未到执行时间")
```

## 🎯 实际应用场景

### 场景1：寄养任务每6小时执行一次

```python
def run_kekkai_utilize_for_all_accounts(self):
    """为所有账号执行寄养任务"""
    for account_info in self.multi_conf.account_list:
        # 检查是否需要执行（6小时间隔）
        if should_run_task(account_info, 'KekkaiUtilize', interval_hours=6):
            # 切换账号
            if self.switch_account_from_game(account_info):
                # 执行寄养任务
                self.execute_kekkai_utilize()
                # 更新时间
                self.multi_conf.update_account_task_time(account_info, 'KekkaiUtilize')
                self.config.save()
```

### 场景2：逢魔任务每天执行一次

```python
def run_demon_encounter_for_all_accounts(self):
    """为所有账号执行逢魔任务"""
    for account_info in self.multi_conf.account_list:
        # 检查是否需要执行（24小时间隔）
        if should_run_task(account_info, 'DemonEncounter', interval_hours=24):
            # 切换账号
            if self.switch_account_from_game(account_info):
                # 执行逢魔任务
                self.execute_demon_encounter()
                # 更新时间
                self.multi_conf.update_account_task_time(account_info, 'DemonEncounter')
                self.config.save()
```

## ⚠️ 注意事项

1. **配置文件兼容性**：旧的配置文件会自动使用默认值 `"2023-01-01 00:00:00"` 填充新字段
2. **保存配置**：更新时间后记得调用 `self.config.save()` 保存配置
3. **任务名称**：确保使用正确的任务名称，否则会记录警告日志
4. **时间格式**：时间格式为 `"YYYY-MM-DD HH:MM:SS"`

## 🔄 迁移指南

如果您已经有旧的配置文件，不需要手动修改。当程序重新加载配置时，Pydantic 会自动为缺失的字段填充默认值。

首次运行后，配置文件会自动更新为包含新字段的格式。

## 📦 多账号日常任务配置说明

### 新增配置项

在 `MultiAccountDailyConfig` 中新增了以下配置项：


### 任务执行逻辑

1. **常规日常任务**：每次运行都会执行（如果启用）
   - 每日召唤
   - 收取友情点
   - 收取吉闻
   - 商店签到/购买体力
   - 道馆突破
   - 御魂副本
   - 觉醒副本
   - 经验妖怪
   - 金币妖怪

2. **定时任务**：根据时间间隔判断是否执行
   - 结界寄养：根据 `kekkai_utilize_interval` 判断
   - 结界挂卡：根据 `kekkai_activation_interval` 判断
   - 逢魔之时：根据 `demon_encounter_interval` 判断

### 执行流程

```
遍历所有账号
  ├─ 检查是否需要登录（基于 last_complete_time）
  ├─ 切换账号
  ├─ 执行常规日常任务
  ├─ 执行定时任务
  │   ├─ 检查寄养任务是否到时间
  │   │   └─ 执行并更新 last_kekkai_utilize_time
  │   ├─ 检查挂卡任务是否到时间
  │   │   └─ 执行并更新 last_kekkai_activation_time
  │   └─ 检查逢魔任务是否到时间
  │       └─ 执行并更新 last_demon_encounter_time
  └─ 更新 last_complete_time
```

### 使用建议

1. **寄养任务间隔**：建议设置为 6 小时，这样一天可以执行 4 次
2. **挂卡任务间隔**：建议设置为 6 小时，与寄养任务同步
3. **逢魔任务间隔**：建议设置为 24 小时，每天执行一次
