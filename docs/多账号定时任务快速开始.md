# 多账号定时任务快速开始指南

## 🎯 功能概述

现在多账号日常任务支持为每个小号单独记录和执行以下定时任务：

- **结界寄养** (KekkaiUtilize)：可设置 1-24 小时间隔
- **结界挂卡** (KekkaiActivation)：可设置 1-24 小时间隔
- **逢魔之时** (DemonEncounter)：可设置 1-48 小时间隔

每个账号的任务执行时间独立记录，互不影响。

---

## 🚀 快速配置

### 步骤 1：启用多账号日常任务

在前端界面或配置文件中启用 `MultiAccountDaily` 任务：

```json
{
  "multi_account_daily": {
    "scheduler": {
      "enable": true,
      "next_run": "2025-11-13 18:05:00"
    }
  }
}
```

### 步骤 2：配置账号列表

确保已经配置好账号列表（在 `config/switch.json` 中）：

```json
{
  "multi_account_daily": {
    "multi_account_config": {
      "account_count": 3
    },
    "account_list": [
      {
        "character": "陸月是你的謊言",
        "svr": "雀之羽",
        "account": "jiyibanana@163.com",
        "account_alias": "jiyibanana",
        "apple_or_android": false
      },
      {
        "character": "柒月是你的謊言",
        "svr": "雀之羽",
        "account": "jiyibanana2@163.com",
        "account_alias": "jiyibanana2",
        "apple_or_android": false
      },
      {
        "character": "捌月是你的謊言",
        "svr": "雀之羽",
        "account": "jiyibanana3@163.com",
        "account_alias": "jiyibanana3",
        "apple_or_android": false
      }
    ]
  }
}
```

### 步骤 3：启用定时任务

在配置中启用需要的定时任务：

```json
{
  "multi_account_daily": {
    "multi_account_config": {
      "account_count": 3,
      
      // 常规日常任务
      "one_summon": true,
      "friend_love": true,
      "luck_msg": true,
      "store_sign": true,
      "buy_sushi_count": 3,
      "souls": true,
      
      // 定时任务
      "kekkai_utilize": true,
      "kekkai_utilize_interval": 6,
      
      "kekkai_activation": true,
      "kekkai_activation_interval": 6,
      
      "demon_encounter": true,
      "demon_encounter_interval": 24
    }
  }
}
```

## ⚙️ 配置说明

### 定时任务配置项

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `kekkai_utilize` | bool | false | 是否启用结界寄养 |
| `kekkai_utilize_interval` | int | 6 | 寄养任务间隔（小时），范围 1-24 |
| `kekkai_activation` | bool | false | 是否启用结界挂卡 |
| `kekkai_activation_interval` | int | 6 | 挂卡任务间隔（小时），范围 1-24 |
| `demon_encounter` | bool | false | 是否启用逢魔之时 |
| `demon_encounter_interval` | int | 24 | 逢魔任务间隔（小时），范围 1-48 |

### 推荐配置

#### 配置方案 1：高频寄养挂卡

适合需要频繁蹭卡的玩家：


## 📊 执行逻辑

### 任务执行流程

```
MultiAccountDaily 任务启动
  │
  ├─ 遍历账号列表
  │   │
  │   ├─ 账号 1: 陸月是你的謊言
  │   │   ├─ 切换账号
  │   │   ├─ 执行常规日常任务
  │   │   │   ├─ 每日召唤
  │   │   │   ├─ 收取友情点
  │   │   │   ├─ 御魂副本
  │   │   │   └─ ...
  │   │   ├─ 执行定时任务
  │   │   │   ├─ 检查寄养任务（上次: 14:00, 间隔: 6h, 现在: 20:30）✅ 执行
  │   │   │   ├─ 检查挂卡任务（上次: 18:00, 间隔: 6h, 现在: 20:30）❌ 跳过
  │   │   │   └─ 检查逢魔任务（上次: 19:00, 间隔: 24h, 现在: 20:30）❌ 跳过
  │   │   └─ 更新 last_complete_time
  │   │
  │   ├─ 账号 2: 柒月是你的謊言
  │   │   └─ ... (同上)
  │   │
  │   └─ 账号 3: 捌月是你的謊言
  │       └─ ... (同上)
  │
  └─ 设置下次运行时间
```

### 时间判断逻辑

对于每个定时任务，系统会：

1. 读取该账号该任务的上次执行时间（如 `last_kekkai_utilize_time`）
2. 计算时间差：`当前时间 - 上次执行时间`
3. 判断是否达到间隔：`时间差 >= 配置的间隔`
4. 如果达到间隔，执行任务并更新时间
5. 如果未达到间隔，跳过任务并记录剩余时间

## ⚠️ 注意事项

1. **首次运行**：首次运行时，所有账号的任务时间都是默认值 `2023-01-01 00:00:00`，因此所有定时任务都会执行一次

2. **配置保存**：任务执行后会自动保存配置，无需手动操作

3. **任务失败**：如果某个任务执行失败，不会更新该任务的时间，下次运行时会重新尝试

4. **时间间隔**：建议根据实际需求设置合理的时间间隔，避免过于频繁导致资源浪费

5. **账号切换**：如果账号切换失败，会尝试登录第一个配置的账号，避免停留在登录界面

## 🔧 故障排查

### 问题 1：定时任务没有执行

**可能原因**：
- 任务未启用（`kekkai_utilize: false`）
- 时间间隔未到
- 账号切换失败

**解决方法**：
1. 检查配置文件中任务是否启用
2. 查看日志中的剩余时间提示
3. 检查账号配置是否正确

### 问题 2：任务执行失败

**可能原因**：
- 游戏界面异常
- 网络问题
- 任务配置错误

**解决方法**：
1. 查看详细错误日志
2. 检查游戏是否正常运行
3. 手动执行一次该任务测试

### 问题 3：时间记录不准确

**可能原因**：
- 配置文件未正确保存
- 任务执行中断

**解决方法**：
1. 检查配置文件权限
2. 确保任务正常完成
3. 手动修改配置文件中的时间字段

## 💡 使用技巧

1. **合理设置间隔**：根据游戏机制和个人需求设置合理的时间间隔
2. **错峰执行**：可以为不同账号设置不同的初始时间，避免同时执行
3. **监控日志**：定期查看日志，确保任务正常执行
4. **备份配置**：定期备份配置文件，避免数据丢失
