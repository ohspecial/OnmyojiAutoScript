# 多账号日常任务 (MultiAccountDaily)

## 功能简介

这个任务模块可以自动切换多个游戏账号，并为每个账号执行配置的日常任务。

## 主要特性

- ✅ 支持多个账号自动切换
- ✅ 智能判断账号登录时机（每天早上5点和晚上18点）
- ✅ 支持执行多种日常任务
- ✅ 自动记录每个账号的最后登录时间
- ✅ 失败自动跳过，不影响其他账号

## 支持的日常任务

### 日常琐事
- 每日召唤
- 收取友情点
- 收取吉闻
- 商店签到
- 购买体力

### 其他日常
- 道馆突破
- 御魂副本
- 觉醒副本
- 经验妖怪
- 金币妖怪

## 配置说明

### 账号配置

每个账号需要配置以下信息：

- **character**: 角色名字
- **svr**: 角色所在服务器
- **account**: 登录账号（邮箱或手机号）
- **account_alias**: 账号别名（可选，用于OCR识别容错）
- **apple_or_android**: 平台选择
  - `true`: 安卓平台
  - `false`: 苹果平台

### 任务配置

在配置中可以选择要执行的日常任务：

```yaml
daily_config:
  one_summon: true          # 每日召唤
  friend_love: true         # 收取友情点
  luck_msg: true            # 收取吉闻
  store_sign: true          # 商店签到
  buy_sushi_count: 2        # 购买体力次数（-1表示不购买）
  dokan: true               # 道馆突破
  souls: false              # 御魂副本
  awakening: false          # 觉醒副本
  exp_youkai: true          # 经验妖怪
  gold_youkai: true         # 金币妖怪
```

## 运行逻辑

1. **账号遍历**: 按配置顺序遍历所有账号
2. **登录判断**: 检查账号是否需要登录
   - 距离上次登录超过13小时
   - 早上5点时段（如果上次登录在18点后）
   - 晚上18点时段（如果上次登录在5-18点之间）
3. **账号切换**: 自动退出当前账号，登录目标账号
4. **任务执行**: 按配置执行各项日常任务
5. **记录时间**: 更新账号的最后登录时间
6. **下次运行**: 自动设置下次运行时间（5:05 或 18:05）

## 使用建议

1. **账号数量**: 建议不要配置过多账号，避免单次运行时间过长
2. **任务选择**: 根据实际需求选择要执行的任务，不必全部开启
3. **时间安排**: 任务会在每天5点和18点自动运行，无需手动触发
4. **错误处理**: 如果某个账号切换或任务执行失败，会自动跳过继续处理下一个账号

## 注意事项

⚠️ **重要提示**:
- 确保每个账号的角色名和服务器名配置正确
- 首次使用建议先配置1-2个账号测试
- 如果账号切换失败，检查账号信息是否正确
- 部分任务需要先在对应的任务模块中配置详细参数

## 与 FindJade 的区别

- **FindJade**: 专门用于切换小号做悬赏任务，支持邀请好友
- **MultiAccountDaily**: 通用的多账号日常任务执行器，支持更多任务类型

可以根据需求同时使用这两个模块。

## 故障排查

### 账号切换失败
- 检查角色名和服务器名是否正确
- 检查账号信息是否正确
- 查看日志中的详细错误信息

### 任务执行失败
- 确保对应的任务模块已正确配置
- 检查游戏界面是否正常
- 查看日志中的错误提示

### 时间判断异常
- 检查系统时间是否正确
- 查看账号的 last_complete_time 字段
