# 协同斗技（DraftDuel）

任务在「每周任务 → 协同斗技」，默认关闭。游戏内入口在町中，名称为「协同对弈」。脚本按北京时间判断开放时段：工作日 10:00–23:00，周末 08:00–23:00；关闭时自动延到下一次开放。

- 单开试玩：匹配模式设为「单人」，大轮数先设为 1。
- 游戏内组队：分别选择「队长」和「队员」。队长在好友名单填队员的游戏名，协同脚本留空。
- 同机双开：启动两个本地实例并启用任务，分别设为「队长」和「队员」。双方在「协同脚本」互填对方的实例配置名，队长在好友名单填队员的游戏名。配对后会在调度空闲时唤醒队友、确认入房并同步选人与上阵。

任务流程、识别资源和策略数据移植自 [xylolit-mu/OnmyojiAutoScript 的 self 分支](https://github.com/xylolit-mu/OnmyojiAutoScript/tree/96215a7a99dc9fbe8858c7a94ed341c16519ef21/tasks/DraftDuel)，基准提交为 `96215a7a99dc9fbe8858c7a94ed341c16519ef21`。本地适配了任务菜单、调度、邀请、蒙版识别和模拟器拖动。对局统计与调试检查点写入 `data/DraftDuel/`，双开同步状态写入 `data/cooperation/`，选人详情截图写入 `tasks/DraftDuel/fight_result/`。
